# 🌟 Amplifica - Marketing, Audiovisual e Estratégias Digitais

Este é o repositório oficial do site da **Amplifica**, um estúdio especializado em **marketing digital, produção audiovisual, fotografia profissional e campanhas digitais**.  
O projeto foi desenvolvido com **HTML5, TailwindCSS, SwiperJS e AOS** para criar uma experiência moderna, responsiva e visualmente envolvente.

---

## 🚀 Tecnologias Utilizadas
- **HTML5** → Estrutura do site  
- **TailwindCSS** → Estilização responsiva e utilitária  
- **SwiperJS** → Carrossel animado no portfólio  
- **AOS (Animate on Scroll)** → Animações de entrada ao rolar a página  
- **JavaScript Vanilla** → Efeitos interativos (logo com zoom + fade e botões animados)  

---

## 📸 Funcionalidades
- 🎥 **Vídeo em background** com fallback `.webm` e `.mp4`  
- 🎨 **Fonte personalizada "Salvatore"** integrada ao design  
- 🔗 **Botão flutuante do Instagram** com efeito hover  
- 🌀 **Logo animada** com **zoom + fade out** ao rolar a página  
- 🖼 **Carrossel de Portfólio** destacando serviços principais  
- 📱 **Layout responsivo** otimizado para desktop, tablet e mobile
